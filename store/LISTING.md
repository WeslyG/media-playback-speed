# Chrome Web Store listing

Name: Media Playback Speed
Language: English
Category: Tools

Change HTML5 video and audio playback speed with toolbar presets and keyboard shortcuts. Pick a preset from 0.5× to 10× or adjust in 0.1× and 1× steps. The toolbar icon shows the current speed when it differs from 1×. Playback information is processed locally.

## Single purpose

Control and display HTML5 audio and video playback speed.

## Permission justifications

- scripting: Read and change playback speed in the selected tab and its supported frames.
- HTTP/HTTPS host access: Find media players and update the toolbar indicator when their speed changes.
- file access: Support local video and audio when file access is enabled in the browser.

## Privacy

No externally transmitted or retained user data. Use the published URL of PRIVACY.md for the privacy policy field.
